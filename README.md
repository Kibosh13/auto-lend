# Natural Gas RE:PORT

Одностраничный аналитический сайт для энерготрейдеров с серверной загрузкой публикаций из Telegram.

## Локальный запуск

Требуется Node.js 22.13 или новее.

```bash
npm install
npm run dev
```

Проверки перед публикацией:

```bash
npm run lint
npm run build
```

## Настройка Telegram

Скопируйте `.env.example` в `.env.local` и заполните переменные:

- `TELEGRAM_CHANNEL` — публичное имя канала без `@`;
- `SITE_URL` — публичный адрес основного сайта.

Файлы `.env` и `.env.local` исключены из Git. Не добавляйте в репозиторий токены, пароли или другие секреты.

## Статическая демонстрация

Версия для GitHub Pages находится в каталоге `static-demo` и публикуется из ветки `gh-pages`. Она не требует сервера и содержит демонстрационные публикации.

В статической версии недоступны:

- автоматическая загрузка новых постов из Telegram;
- серверный маршрут `/api/telegram`;
- обновление ленты без новой публикации ветки `gh-pages`.

Индексация демоверсии закрыта одновременно через meta robots и `robots.txt`. GitHub Pages остаётся публично доступной по прямой ссылке.
